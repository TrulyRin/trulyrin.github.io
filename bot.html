Depths Saviors Bot

Community tools for moderation, verification, and Deepwoken activities in the main Depths Saviors server.

Main Server Only • Private Community Bot

What Does the Bot Do?

The bot helps staff moderate configured channels, verify members, answer common questions, and run community activities. Members can use commands available to their role. Public installation and cross-server alliance features have been retired.

Member Verification

Join checks and optional browser verification help staff review possible alternate accounts.

Community Moderation

Format checks, forum moderation, and FAQ replies support configured channels.

Deepwoken Utilities

Build previews, tryouts, points, and role commands support activity in the main server.

Using the Bot

VerificationUse the personal link provided by the bot and read the privacy notice first.
Posting rulesFollow pinned formats in channels with automated checks.
Member toolsUse the commands available to your role in the main server.
Staff dashboardAuthorized main-server administrators can manage private modules through the dashboard.
