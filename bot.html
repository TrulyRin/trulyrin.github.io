What Is Gank Ping Bot?

Gank Ping Bot is a secure alliance tool for competitive guild play. It links Discord servers into a unified network for instant gank alerts. Featuring a manual approval system to block spies and activity tracking to catch leeches, it ensures your alliance stays fast, accountable, and ready for war. Use /gankhelp to start. This system is built for speed and security in high-stakes environments.

Instant Gank Alerts

Broadcast rescue requests across all allied servers simultaneously. Location, screenshots, and role pings included.

Spy Protection

Manual approval system ensures only trusted guilds join. No random servers, no leaks, no compromises.

Activity Tracking

Track who responds, who ignores, and who leads. /gankstats exposes leeches and rewards active members.

Core Commands

/gankhelp Full command reference and setup walkthrough.
/gank Send a gank alert to all allied servers with location and screenshot.
/setchannel #channel Set the channel where gank alerts appear in your server.
/setgankping @Role Set the role to ping when a gank alert is received.
/setallyrole @Role Set which role can send gank alerts (admins always can).
/gankstats View leaderboards for response times, calls, and attendance.
