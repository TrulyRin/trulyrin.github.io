Depths Saviors Bot

Private tools for our main Discord server.

For members

Use the verification link provided in Discord, follow channel posting rules, and use commands available to your role. Ask staff if a verification or moderation decision seems wrong.

For staff

The dashboard requires Discord sign-in and Administrator access in the main server. Review automated results before acting on them.

How the bot uses Discord data

Server Members access supports join checks and member tools. Message Content access supports formatting checks, forum moderation, FAQ matching, proof detection, and link previews in configured channels. Some FAQ and forum content may be sent to Hugging Face or Google Gemini. See the Privacy Policy for details.

Retired public features

Public installation, alliance setup, cross-server gank alerts, and public billing offers are archived. The bot is only for the Depths Saviors main server. Old public setup instructions no longer apply.
