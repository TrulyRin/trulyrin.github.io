Privacy Policy

Last updated: September 28, 2026

1. Scope and operators

This policy covers the Depths Saviors bot, website, staff dashboard and verification page, operated by Rindw and Zako_tb. The bot serves the main Depths Saviors Discord server. The website and this policy are publicly readable; bot functions and staff settings are restricted to the community and the appropriate roles.

Public installation, external-server setup and cross-server gank broadcasts have been retired. Archiving their code does not automatically delete records previously created by those features.

2. Discord data and its purposes

  • Account and server information: Discord user, server, channel, role and message IDs; usernames, avatars, account age, membership and permissions, as needed for sign-in, access checks, join checks and staff tools.
  • Messages and attachments: text, post titles, links and relevant images or attachments in configured workflows, used for formatting checks, forum moderation, FAQ matching, proof review and Deepwoken build previews.
  • Community records: points, proof references or hashes, tryout and role configuration, moderation or verification results, and guild utility records. Staff reports and operational logs may include user IDs and relevant message details.

Automatic message checks run in configured channels without requiring a slash command. The bot does not currently provide an individual switch to opt out of those checks while posting there. Contact staff about a concern before using the affected channel. Leaving the server does not automatically erase existing records.

3. Browser verification

When you choose to verify, the page produces a browser/device fingerprint and sends it with your Discord user ID and verification details to our bot API. The fingerprint can use canvas, WebGL, audio-rendering and browser/hardware characteristics. Browser metadata includes user agent, platform, screen dimensions, language, timezone, touch capability, reported CPU core count and device memory where available.

Verification information is stored on the bot host and sent to the configured staff verification channel on Discord. Staff use it to compare linked accounts, review possible ban evasion and apply configured verification actions, which may include a role change, kick or ban.

This data is linked to your Discord account; it is not anonymous. A fingerprint match is a signal that can be wrong, particularly on shared devices. Contact an operator for review of an incorrect result. You can decline browser verification by leaving the page, but access to protected channels may remain restricted; discuss available help with staff.

4. Website storage and sign-in

The website stores your light/dark theme preference in local storage. Verification uses a local marker to remember a submitted link. Dashboard authentication uses a server-side Discord OAuth session and a session cookie; logout ends that session. The verification sign-in flow may temporarily receive a Discord access token to confirm the account being verified.

Older dashboard versions stored Discord access tokens in local storage. The updated dashboard and legacy callback clear those old entries when opened. Clearing site data removes local preferences and markers, but does not delete records held by the bot or Discord.

Web hosting, API hosting and delivery providers receive ordinary connection information such as IP address, user agent and request details when you use their services. Error or security logs may contain that information.

5. Providers and disclosure

Data is processed by services necessary to run these features:

  • Discord provides authentication, server events, messages, attachments and staff reports.
  • Cybrancee hosts the bot, its stored records and API. The website source is hosted on GitHub; hosting and delivery services handle website requests.
  • Hugging Face may receive FAQ question text to generate embeddings for matching prepared answers.
  • Google Gemini may receive selected forum text, titles and images for moderation classification.
  • Deepwoken Planner receives requests for build data when its links are previewed. Website assets and verification scripts may load from Google Fonts, Discord CDN, cdnjs, jsDelivr and the FingerprintJS CDN, which receive connection information.

Authorized operators and relevant server staff can access records needed for support and moderation. Feature output is visible to people who can access the relevant Discord channels. We do not sell Discord data or provide it for advertising. Our bot uses AI services for inference, not to train its own models; each provider also applies its own service terms and data practices.

6. Retention, access and deletion

The current bot does not enforce a general automatic 30-day deletion schedule. Verification fingerprints, linked account IDs, moderation records, utility data and logs may remain until manually removed. Old public-feature data and backups may also remain; retiring a feature alone does not erase them.

To request access, correction or deletion, open a support ticket in Depths Saviors or contact @Rindw or @Zako_tb on Discord. If you cannot enter the server, contact an operator directly. Include your Discord user ID and the records concerned. Staff may verify ownership before acting.

Deletion requires manual handling and may disable features that rely on the removed records. Discord messages and provider-held logs or backups are separate from bot storage and may require separate handling. Ask the operators to explain any records they cannot remove or any retention needed for an unresolved safety issue or legal obligation. No fixed completion time or backup deletion schedule is currently promised.

7. Security

The website and production API use HTTPS, verification links are signed, and staff settings require authenticated permission checks. Fingerprinting and hashing do not make account-linked data anonymous. This policy does not claim that all stored records or backups are encrypted at rest; that has not yet been confirmed with the host. No system can guarantee absolute security.

8. Updates and contact

This page will be updated when the bot’s scope or data practices change. For privacy questions, deletion requests, security concerns or a review of automated decisions, contact @Rindw or @Zako_tb through Discord. Also see our Terms of Service and support guide.
